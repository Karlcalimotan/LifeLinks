# Attributions

LifeLink's architecture was informed by the OptiFeed capstone (MIT): the
versioned device-configuration envelope, the hash-and-compare device token
pattern, the event-log projection, the request envelope and the native-test split
for Arduino-free headers. The vehicle-alert domain, Prisma schema, UI, API
routes and firmware implementation here are new.

The LifeLink names, copy, demo data and the signal-plate logo are original. No
OptiFeed branding, datasets, keys or user data are included.

The console uses **Barlow** and **Barlow Condensed** from Google Fonts, licensed
under the SIL Open Font License 1.1. The visual direction was informed by
Anthropic's public `frontend-design` skill; no skill code is included.
